# The Architecture of Silence
The words are the **interface**. In NotBad, markdown marks recede into the canvas so the piece looks finished while being written.
Markdown editors traditionally force a compromise: either stare at raw markup syntax or introduce split preview panes. Both add friction between the author and the prose.
## Conceal, Don't Remove
